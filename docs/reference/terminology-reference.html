Core Framework Terminology

Agent Types

    1. APEX: Strategic direction and architecture agent
    2. ANALYST: Data analysis and optimization agent
    3. HISTORIAN: Documentation and knowledge management agent

Protocol Files

    1. AGENT.md: Agent identity and role definition file
    2. STATUS.md: Current operational status and priorities file
    3. AUTO-COMPACT.md: Context management and recovery information file

System Components

    1. AAR System: After Action Review documentation system for learning and context preservation
    2. Context Management System: Optional system for tracking and visualizing context utilization
    3. Protocol-Based Recovery: Standardized recovery mechanism for context resets
    4. Workspace Standardization: Consistent file structure and organization

Context Management Terminology

Context States

    1. Utilization: Percentage of context window currently in use
    2. Checkpoint: Serialized state snapshot for recovery
    3. Threshold: Defined utilization level triggering actions
    4. Auto-Compact: Context reset process to clear window

Threshold Levels

    1. Notice (65%): First level threshold creating checkpoint
    2. Warning (75%): Second level threshold with caution notification
    3. Alert (85%): Critical threshold offering auto-compact

Operation Types

#### User Messages

    1. USER_SMALL: Brief messages (~750 tokens)
    2. USER_MEDIUM: Standard messages (~2200 tokens)
    3. USER_LARGE: Detailed messages (~4400 tokens)

#### Assistant Responses

    1. ASSISTANT_SMALL: Brief responses (~1500 tokens)
    2. ASSISTANT_MEDIUM: Standard responses (~4400 tokens)
    3. ASSISTANT_LARGE: Detailed responses (~10000 tokens)

#### Tool Operations

    1. TOOL_READ_SMALL: Small file reads (~1500 tokens)
    2. TOOL_READ_MEDIUM: Medium file reads (~4400 tokens)
    3. TOOL_READ_LARGE: Large file reads (~7500 tokens)
    4. TOOL_WRITE: File writing operations (~750 tokens)
    5. TOOL_EDIT: File editing operations (~1500 tokens)
    6. TOOL_TASK: Task tool executions (~6000 tokens)

Workspace Terminology

Directory Structure

    1. /AAR/: After Action Review documentation
    2. /projects/: Active project implementation files
    3. /reports/: Generated reports and documentation
    4. /archives/: Archived implementation artifacts
    5. /tools/: Utility scripts and tools
    6. /checkpoints/: Context recovery checkpoints

File Naming Conventions

    1. Protocol Files: UPPERCASE-WITH-HYPHENS.md
    2. Session AARs: YYYY-MM-DD-description.md
    3. Incident AARs: DESCRIPTIVE-NAME-RCA.md
    4. Scripts: verb-noun.sh or verb-noun.js

Recovery Terminology

Recovery States

    1. Recognition: Identification of context reset
    2. Identity Restoration: Regaining agent identity
    3. Context Loading: Retrieving implementation context
    4. Work Resumption: Continuing operations with recovered context

Recovery Metrics

    1. Recovery Time: Exchanges needed for full operational awareness
    2. Context Retention: Percentage of knowledge preserved across resets
    3. Recovery Completeness: Degree of state restoration

Success Metrics Terminology

    1. Recovery Time: ≤1.0 exchanges to full operational awareness
    2. Context Retention: ≥90% knowledge preservation across resets
    3. Response Time: ≤500ms for standard operations
    4. Task Completion: ≥95% successful completion rate
    5. Protocol Compliance: 100% on critical requirements

Conclusion

This terminology reference provides a standardized vocabulary for working with Trinity Framework 2.0 Core. Consistent use of these terms ensures clear communication, effective documentation, and operational resilience across context limitations.
