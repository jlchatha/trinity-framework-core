Troubleshooting Common Issues

Protocol File Issues

    1. Problem: Missing sections in protocol files
    2. Solution: Copy from templates in /templates/protocol-files/

Directory Structure Issues

    1. Problem: Missing required directories
    2. Solution: Create missing directories: mkdir -p [missing-directory-path]

Permission Issues

    1. Problem: Scripts not executable
    2. Solution: Run chmod +x [script-path]

Context Tracking Issues

    1. Problem: Context tracking not functioning
    2. Solution: Verify Node.js installation and create required directories

After Verification

Once your workspace passes all verification checks:

  1. Document Completion: Create an AAR session documenting the verification
  2. Update STATUS.md: Mark verification as complete
  3. Begin Operations: Start using the workspace for its intended purpose
  4. Regular Compliance Checks: Schedule periodic verification checks
